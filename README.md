# Entropy-Based Image Segmentation

This repository contains the Python implementation of research work on entropy-based image segmentation and thresholding.

The project investigates two approaches:

- **Non-Additive Cumulative Residual Entropy (NCRE):** An expectation-weighted approach to cumulative residual entropy-based image thresholding.
- **Generalized Cumulative Residual Tsallis Entropy (GCRTE):** A generalized entropy-based segmentation approach using Differential Evolution for parameter optimization.

The repository also includes implementations of conventional entropy-based thresholding methods and comparative evaluation on infrared, Weizmann, NDT, and selected BSD images.
